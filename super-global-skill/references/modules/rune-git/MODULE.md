# rune-git

1. Inspect status, branch and diff; preserve existing user changes and repository commit conventions.
2. Stage only intended files, resolve conflicts by behavior and verify the result. Push, merge or rewrite shared history only within explicit authorization; attach created PRs using the available app tool.

Use current session tools and repository conventions. Scale checks to risk; do not recursively load other skills or assume permission from this file.

For domain-specific detail beyond these steps, inspect [references/index.md](references/index.md) and read only the relevant source section.
