# workflow-orchestrator

1. Use one canonical plan containing scope, acceptance criteria, ordered outcomes and relevant verification. Keep routine short work inline.
2. Execute the next dependency-ready outcome; revise the plan when facts change. Do not require extra approvals already covered by the user request.
3. At stage boundaries, capture only decisions, changed paths, check results and next action. Reuse repository task files instead of creating competing journals.
4. Before completion, compare every promised outcome against a current artifact and meaningful check. A zero-target scan is inconclusive.
5. Record a reusable lesson only for a demonstrated failure or user correction; avoid speculative rules and transcript-sized retrospectives.
