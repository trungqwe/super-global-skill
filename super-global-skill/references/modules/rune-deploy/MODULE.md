# rune-deploy

1. Identify the target, credentials mechanism, build command, migration order and rollback artifact; run applicable pre-deploy checks.
2. Deploy within the user's authorization, verify a meaningful live path and record release identity. Ask only for missing authorization or information; never treat a build as a live health check.

Use current session tools and repository conventions. Scale checks to risk; do not recursively load other skills or assume permission from this file.

For domain-specific detail beyond these steps, inspect [references/index.md](references/index.md) and read only the relevant source section.
