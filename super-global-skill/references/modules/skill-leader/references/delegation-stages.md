# Stage selection

Use one primary for the current outcome. A task moving between stages does not imply spawning agents.

- Scope/plan: workflow-orchestrator when a durable staged plan is needed.
- Architecture: architecture-solution-review for consequential alternatives.
- Implement: autonomous-project-ops; use rune-fix for a bounded fix.
- Diagnose: rune-debug when the cause is unclear.
- Verify: rune-verification when check selection or evidence is the task.
- Review: rune-review; rune-review-intake for external comments.
- Handoff: context-memory-ops.
- Skill authoring: skill-creator.

For office artifacts and browser interactions prefer the current format/tool skill. Use rune-team only for requested or otherwise permitted independent parallel work.
