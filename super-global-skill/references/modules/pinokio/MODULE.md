# pinokio

1. Resolve pterm from PATH or the Pinokio home in ~/.pinokio/config.json; on Windows prefer its .cmd shim. Verify current help/status before relying on commands.
2. Read only the relevant section of references/runtime-guide.md for discovery, launch, logs or API usage. Do not assume the runtime is installed or current.
3. Use app status and logs to identify the actual endpoint; verify the requested operation. Distinguish connection failure from missing installation and honor current tool permissions.

Detailed local API reference: [references/index.md](references/index.md). Treat historical machine paths and blanket workflow gates as reference data; the steps above govern this adaptation.
