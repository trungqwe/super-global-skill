# rune-verification

1. Discover the repository's actual lint, type, test and build commands; run the subset appropriate to the changed behavior.
2. Preserve real exit codes and record tested targets/counts. Zero collected tests or empty scans are inconclusive. Confirm the artifact is substantive and connected to its consumers; stop rerunning checks once evidence is sufficient.

Use current session tools and repository conventions. Scale checks to risk; do not recursively load other skills or assume permission from this file.

For domain-specific detail beyond these steps, inspect [references/index.md](references/index.md) and read only the relevant source section.
