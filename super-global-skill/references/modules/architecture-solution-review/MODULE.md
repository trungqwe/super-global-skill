# architecture-solution-review

1. Read the existing constraints and affected implementation. Research unstable facts using versioned primary sources.
2. For a consequential open design, compare at least three materially distinct viable options; do not fabricate alternatives when constraints leave fewer.
3. Compare fit, operational cost, migration risk, security, performance and reversibility. Use explicit weights only when they clarify the decision.
4. Recommend one path with evidence, assumptions and a disconfirming experiment. Define migration stages, compatibility requirements, rollback limits and success criteria.
